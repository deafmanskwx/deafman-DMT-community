# DMT 2.5.2 Release Notes

DMT 2.5.2 improves colour workflow consistency, adds more precise curve editing, and resolves issues with version commits and matrix injection.

## Improvements

- Overhauled the colour pipeline so adjustments made with ColourOps and the Engine colour sliders now transition seamlessly.
- Added Bezier curves to the Perception Map for more precise compensation-curve editing.

## Fixes

- Fixed inconsistent results when using **Commit to Version**.
- Fixed **Inject to Matrix** not working as expected from the Master Grade Group context menu.
