# DMT 2.1.3 Release Notes

## Highlights

- Tracks sensitivity now works within active secondary colour filters. After selecting a family such as Red, Green, Blue, or Purple, increasing the sensitivity slider progressively reveals matching colours without allowing colours from other families back into the result.
- Reverse colour search and screen colour sampling now show distinct guidance while each picker is active, making the current operation clear before a colour is selected.

## Notes

DMT 2.1.3 is a focused Tracks and colour-picking refinement that makes filtered palette exploration more predictable and on-screen picker guidance more precise.
