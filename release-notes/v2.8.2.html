DMT 2.8.2

Retain clip colour groups during automatic colouring, cycle harmony directives in either direction, and see the active screen-picker mode.

  • Preserve clip groups: enable PRESERVE EDITS in Tracks > CFG > CLIP COLOURING, with automatic clip colouring on. The main colour group follows the track; other groups use ANALOGOUS, COMPLEMENTARY, LUMA or RAND.
  • Shared choices: preservation settings are saved per theme and retained when switching harmony directives.
  • Responsive clip updates: preservation processes clips in small steps to keep Live responsive.
  • Reverse cycling: Shift-click the harmony-directive label to cycle backwards.
  • Screen-picker modes: P identifies parameter search; C identifies colour selection.

Live device update: replace the DMT-Tracks Max for Live device in your Live set with the device included in this version.
