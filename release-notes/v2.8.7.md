# DMT 2.8.7 Release Notes

DMT 2.8.7 is a hotfix for window zoom in **Tracks**.

- Fixed clicks landing on the wrong palette swatch, filter chip or sidebar button when window zoom was above or below 100%. In the compact **Tracks Tweek** window, clicking a control could also start a window drag.
- The Tracks panel now fills the space between the header and footer when you zoom in or out, keeping the edges of the palette in view.
- Hold **Shift** to reveal the full palette, including while choosing colours with **SEL** or **ALL**. Release Shift to return to your filtered palette.
- In **Tracks > MAP**, select tracks in Ableton Live and click **ADD RULE** to create one rule for that selection. When several tracks share a MAP rule, applying a colour with **SEL** updates the mapping for just the selected tracks.

To use the updated MAP controls, replace the **DMT-Tracks** Max for Live device in your Live set with the copy included in this release.
