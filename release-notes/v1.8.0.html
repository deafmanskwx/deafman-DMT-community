Theme Library

  • Cmd-clicking a Theme Library folder now expands or collapses the current tree while keeping the top-level COMPLETE root stable.
  • Manual imports of older first-party standalone packs now appear correctly under Complete, with the imported pack version selected after import.

Editor

  • The Engine eye control now opens Memory and History colour swatches, with persistent favourites, real interaction history, apply actions, and preset context menus.
  • Theme Editor search now keeps a compact recent-search history for parameters, groups, and Blends, available from the search bar or Option+Down.
  • Pressing § opens the Theme Editor reverse colour search picker and expands into the full editor layout when needed.
  • Color suppressor controls now peak cleanly on selected hues, improving targeted chroma reduction.

Macros

  • Cmd-clicking a Macro Editor macro title collapses every macro header at once.
  • Macro route range handles now support Snap to Cursor from their context menu.
  • Macro route range fills now support Reset from their context menu.
  • Tint ColourOP now has separate Hue and Saturation macro routes, matching the paired-control workflow used by Grade XY.

AutoSetup

  • Selected eligible Theme Library rows now offer a direct SETUP button for launching AutoSetup.
  • Group Setup now separates Simple/Detailed layouts from Z-Depth, with Z-Depth AutoSetup presented as one Near/Mid/Far page.
  • Macro headers now include BYP controls for routed colour operators and drag handles for reordering macros within the active AutoSetup step.
  • AutoSetup macro rows now expose BYP beside the slider, mirroring Macro Editor bypass controls.

Settings

  • Content updates can now be installed automatically in the background or reviewed manually, with eligible packs listed individually and pending installs available from the Theme Library update control.

Tracks

  • Tracks tuneables now include an inline UNIFORM shortcut for toggling track and group uniform-colouring states together.
  • Tracks sensitivity now offers Refresh On Release or Realtime modes from the slider thumb context menu.
  • Tracks analysis labels can now be click-drag painted across rows, matching the existing analysis weight-bar workflow.
  • While the Tracks quick CFG submenu is open, Cmd-scroll adjusts group-member offset directly.
  • Tracks sort controls can cycle HUE, SPREAD, and PING frequencies through 1/2/3 on repeated selection.
  • Tracks UNIFORM now cycles through the final OFF/ALL, combined, group-only, and track-only uniform states.
