# DMT 2.8.0 Release Notes

Tracks colour updates are much faster, and clips can now follow their track colours automatically.

## Automatic clip colouring

- **Command-click CLP** to turn automatic clip colouring on or off. The CLP label lights up while it is enabled.
- **Session and Arrangement clips** follow colours applied to their tracks by DMT, including palette and sensitivity adjustments.
- **Manual track commands** also update clips on the affected tracks, including SEL, ALL, audio/MIDI commands, group colouring and MAP rules.
- **Clip dimming** carries through to automatic colouring using your existing dimming amount.
- **Saved preferences** remember the automatic clip-colouring setting separately for each harmony directive. It starts off by default.

## Faster Tracks colour updates

Track colours refresh almost in real time while you drag the sensitivity slider, with substantially faster colour updates across your Live set.

Automatic clip colouring combines rapid palette and sensitivity edits into the latest clip colour instead of repeating every intermediate update. Unchanged track colours skip unnecessary clip work, keeping Tracks responsive while clips follow along.

Manual CLP choices remain in place until the next track-colour or dimming change. 2TRK preserves existing clip-colour variations when taking the track colour from its clips; automatic clip colouring resumes when DMT changes the track again.

## Update the Live device

Replace the DMT-Tracks Max for Live device in your Live set with the device included in DMT 2.8.0 to use these changes.
