# DMT 2.9.2 Release Notes

You can now move through several themes in the Library without loading each one into Live along the way.

## Browsing themes

- Click the Library’s up and down arrows, or press **Shift-Up** and **Shift-Down**. The highlight follows each press. Pause on the theme you want and DMT loads it into Live.
- You can reverse direction while browsing. If you return to the theme already loaded before pausing, DMT keeps it in place. If another theme is still loading, DMT remembers your latest choice and loads it when the current load finishes.
- The arrow’s activity indicator stays visible while the theme loads. If you use **Reduce Motion** in macOS, the indicator stays still.
