# DMT 2.8.4 Release Notes

## Clip colouring while browsing themes

Fixed clips not following track colours when switching themes in the Library with both **Tracks Background Refresh** and **automatic clip colouring** enabled.

Background refresh now respects the CLP automatic colouring setting, **PRESERVE EDITS**, and the selected clip-edit directive while the Tracks tab is closed.

To use automatic clip colouring while browsing, enable **Background Refresh** from the Tracks tab menu and **Command-click CLP** to enable automatic clip colouring.
