# DMT 2.8.1 Release Notes

Automatic clip colouring now uses one shared on/off setting across all harmony directives in the current theme.

## Automatic clip colouring

- **Command-click CLP** to turn automatic clip colouring on or off for the theme.
- **Switch harmony directives** while keeping your current on/off choice.

The CLP label lights up while automatic clip colouring is enabled.
