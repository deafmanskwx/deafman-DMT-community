Auto Setup, Reworked

DMT 2.5.0 makes Auto Setup faster to enter, easier to navigate and more focused in its new Expert layout.

  • Move between Auto Setup areas more directly and open Tracks without losing your place in the Library.
  • Shape hue strips alongside the existing group, macro and depth controls.
  • Preview a Perception setup while editing before committing it to the theme.

Deeper Colour Control

  • Use the new Selective Hue and Suppress operators for more precise colour shaping.
  • Inspect appearance compensation with the compensated-only HUD view.
  • Dark-theme compensation, Perception curves and HLS hue controls now stay more dependable and consistent.

Faster, More Reliable Workflows

  • Auto Setup presentation and window changes respond more quickly.
  • The new Ultra refresh option gives Ableton a stronger theme refresh path.
  • Rendered theme changes, mirror sources and Library readiness remain more stable after edits.

This release turns Auto Setup into a quicker, more capable workspace while adding finer Perception and colour-shaping tools for demanding themes.
