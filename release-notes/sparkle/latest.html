DMT 2.9.6

With MAP open, use the # colour picker to sample a group header or member track in Live and find the matching group. Sample the same colour again to cycle through matches.

If you use Tracks, replace the DMT-Tracks Max for Live device in your set after updating. Drag the new device from the amxd handle in Tracks.

  • Turn on Include loose tracks beside CONVERT or UPDATE to capture ungrouped audio and MIDI track colours.
  • Automatic group colouring can pick an unused swatch with an equal or better theme match when groups would share a colour.
  • Tracks detects duplicate DMT-Tracks devices more reliably, including older copies.
  • Editor reverse colour search swatches update as you edit the theme.
