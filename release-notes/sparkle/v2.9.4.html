DMT 2.9.4

Select Live 13 Beta in the Library and load a Live 12 theme as usual. DMT converts it automatically and keeps the Live 12 original.

DMT’s support for Live 13 is also in beta. Some colours or contrasts may look slightly off in converted themes, especially on controls new to Live 13. We’ll refine the conversion in upcoming updates.

If you use Tracks, replace the DMT-Tracks Max for Live device in your set after updating. Drag the new device from the amxd handle in Tracks.

  • If you have several Live releases or betas installed, click the corresponding target button to choose one. Each button remembers its own selection.
  • Theme packs can include Live 12 and Live 13 versions under one Library entry. DMT loads the version for the selected installation.
  • Matrix, Tracks, and the font installer all use the selected Live installation.
