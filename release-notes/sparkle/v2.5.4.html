Live Target Reliability

DMT 2.5.4 improves Live target handling for Ableton Live installations on external volumes and keeps editor selection clear when moving from Auto Setup into Expert.

  • External Live installations are now detected when a volume is mounted, without restarting DMT.
  • The selected Live Target now remains stable during discovery and falls back safely when an external volume is disconnected.
  • Switching Live installations now clears stale working theme files before using the newly selected target.
  • Opening the Expert layout from Auto Setup now restores the editor's previous selection so multiple group selection frames do not remain visible.
