# DeafManTools Community

This public space is for DeafManTools release notes, bug reports, feature discussion, and user support.

DeafManTools itself is proprietary software. This repository does not contain source code, release binaries, content packs, private manifests, signing metadata, license logic, or internal pipeline files.

## What belongs here

- Public release notes
- Bug reports with reproducible steps
- Feature requests and workflow ideas
- Content-pack issues that do not include private license details
- General discussion and support threads

## What does not belong here

- License keys, order IDs, access tokens, or private account details
- DMT `.dmg`, `.dmt`, `.dtf`, appcast, or manifest files
- Source code or internal build/publishing files
- Signing, notarization, Sparkle key, Keychain, or license-manager internals

## Reporting Bugs

Use the bug report template and include:

- DMT version
- macOS version
- Ableton Live version
- Clear steps to reproduce
- What happened and what you expected instead

For license or account recovery, contact support directly instead of posting private details here.
